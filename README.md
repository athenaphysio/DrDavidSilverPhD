## Deployment

This is a static HTML site. All images are embedded as base64 — no external image hosting required.

**To deploy on GitHub Pages:**

1. Push all files in this folder to a GitHub repository
2. Go to repository Settings → Pages
3. Set Source to: Deploy from a branch → main → / (root)
4. Save — the site will be live at yourusername.github.io/repo-name within a few minutes
5. To use drdavidsilverphd.com: add a CNAME file containing `drdavidsilverphd.com`, then set the custom domain in Pages settings and update DNS at your registrar
